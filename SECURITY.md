# Security and data handling

Never report credentials or private scenes in public issues. Rotate a fal key if exposed.

The preview sends images and prompts to fal. Local metadata may include prompts and file paths. Review captures, recordings and logs before sharing; `.env` and outputs are ignored by Git.

Use GitHub private vulnerability reporting if enabled. Otherwise contact the maintainer through an established private channel before disclosing sensitive details. Do not put secrets or exploit details in a public issue.

This experimental fork has no guaranteed security support window. Keep working scenes saved independently.
