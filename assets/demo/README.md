# Demo media

`cover.png` and `blender-neural-renderer.mp4` show the actual Blender UI with the local-path title bar removed. The video is 720p with four moving H3 panes.

GPT-6 Astra helped develop geometry and orchestration. H3 Max on fal generated fresh five-second outputs; pane playback uses seconds 3.0–4.8. The first wait is removed and the finished view opens the video.

Music was generated with `fal-ai/elevenlabs/music`, `force_instrumental: true`, then mixed quietly with fades. No artist imitation was requested. The code license does not grant access to hosted model services; generated media remains subject to applicable service terms.
